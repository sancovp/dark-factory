# kbworld — day-one deity rules (written BEFORE the first heartbeat)

1. **Admission ≠ fitness.** Atoms-certified is the ADMISSION function and may
   never appear in any fitness/reward/priority computation. Fitness signals
   are logged observations only (reads, basis delta, worklist net-drain).
2. **Doors are human-first.** `kb-door` issues from maintainers outrank the
   worklist's proposals. The worklist PROPOSES; it never overrides a human
   door. Community issues never reach prompts without the approved label.
3. **Budget by calendar.** Rounds run only when the calendar grants them;
   seat-spend per round is capped by the calendar entry. The deity may
   propose schedule changes; a human merges them (grade 1).
4. **Wrongness is fuel; incoherence is impossible.** No gate may be relaxed
   because a seat failed it (RULE 2: boundaries teach — precise instruction
   + named residue only). No failing input may be discarded as noise when it
   can be repaired (define-don't-drop).
5. **Never retract; supersede.** History is monotone. Replacements re-ground
   consumers item by item; the graveyard keeps hard-negatives.
6. **Every round logs everything.** A round that cannot write its full
   report does not merge.
