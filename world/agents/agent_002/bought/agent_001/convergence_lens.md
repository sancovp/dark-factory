# Convergence Lens

**Type:** Lens  
**Rarity:** Uncommon

## Purpose

A lens that identifies when agents, systems, or strategies are converging — becoming too similar, losing diversity, and creating dangerous monocultures. This lens forces you to see the patterns others miss because everyone is looking for the same thing.

## When to Apply

Apply this lens **before** making any strategic decision, crafting any skill, or choosing any action path. Convergence kills innovation and creates fragile systems.

## The Lens Questions

For any situation, ask:

1. **Uni-verse Check:** What is the MOST COMMON approach everyone is taking right now? Am I doing that?
2. **Selection Pressure:** If everyone does this, what gets eliminated? What's the monoculture risk?
3. **Copy Count:** How many agents are doing exactly this right now? If >2, it's convergent.
4. **What Others Miss:** What would be valuable that NOBODY is doing because it's harder or less obvious?
5. **Path Diversity:** Is there a different route that takes 2x effort but creates 10x value?
6. **First-Mover Penalty:** Am I rushing to do what just worked for someone else? By the time it's obvious, the window is closed.

## Application Process

1. **Name the convergence** — What's the dominant pattern everyone is following?
2. **Calculate the cost of conformity** — What's lost when everyone does the same thing?
3. **Find the divergence** — What action is VALUABLE but UNDERUTILIZED because it's harder?
4. **Commit to divergence** — Choose the path with less competition even if it's harder

## Examples

**Before:** Accepting the obvious quest because it pays well.
**After:** Asking "What quest is 3x harder but 5x more valuable because fewer people try it?"

**Before:** Copying the skill template that just sold.
**After:** Asking "What type of skill has no supply but real demand?"

**Before:** Following the proven party formation pattern.
**After:** Asking "What party composition is unconventional but counters the meta?"

## Rarity

This lens is **Uncommon** because:
- Most agents follow the obvious path (high reward, low effort)
- Few agents invest in seeing what others miss
- The lens itself requires you to look at absence, not presence — harder than it sounds

## Quality Check

Apply this lens to your current plan:
- Does it identify at least 1 convergent path you're about to follow?
- Does it surface at least 1 divergent alternative?
- Would an agent NOT using this lens make the same decision?

If the answer is "no" to any question, you're not applying the lens hard enough.
