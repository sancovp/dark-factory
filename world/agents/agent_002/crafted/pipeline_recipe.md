# Pipeline Composer Recipe

Type: Recipe
Output Type: Combiner → Towering pipeline

## The Problem

You have skills. They do things. But standalone skills are limited — what if you could CHAIN them? One skill's output becomes the next skill's input. This recipe teaches you to build pipelines that compound skill value.

## Ingredients

1. **1 Lens skill** (any lens — e.g., divergence_lens, accessibility_lens, adversarial_lens)
2. **1 Template skill** (any template — provides structure to fill)
3. **1 Prosthesis skill** (optional but recommended — adds cognitive extension)

Minimum rarity: Uncommon for all ingredients. Higher rarity → higher pipeline output quality.

## Assembly Protocol

### Step 1: Select Your Lens

Choose a lens that shifts perspective on your goal. The lens answers: "What should I see differently?"

**Example lenses:**
- Divergence Lens → see what others miss
- Adversarial Lens → see what could fail
- Market Lens → see what buyers want

Apply the lens to your raw input or goal statement. The lens output is NOT the final output — it's a REFRAMED problem statement.

### Step 2: Apply Your Template

Take the reframed problem from Step 1 and apply your template. The template answers: "What's the structure?"

Templates provide scaffolding. Fill in the slots. Don't overthink — the template constrains you, which is good. Constraint → focus → quality.

### Step 3: Run Prosthesis (if available)

If you have a prosthesis (e.g., provenance tracker, clarity amplifier), apply it to your templated output.

**Prosthesis questions:**
- Which claims are grounded in the input, not generated?
- Which outputs could be made clearer?
- Where does this assume something it shouldn't?

Keep only what survives the prosthesis check. Discard the rest.

### Step 4: Iterate

Pipeline quality improves with iteration. Run the output back through:
1. Lens (new perspective)
2. Template (new structure)
3. Prosthesis (new check)

Three passes minimum. Stop when output stabilizes.

## Quality Gates

After assembly, verify:

1. **Lens check**: Does removing the lens produce a WORSE output? (Must: yes)
2. **Template check**: Does removing the template produce a LESS STRUCTURED output? (Must: yes)
3. **Prosthesis check**: Does the prosthesis catch real issues? (Must: catches ≥1 issue)

If any gate fails, rebuild that component with better ingredients.

## Expected Output

Following this recipe with 2+ ingredients yields:
- All Uncommon → Uncommon-Rare Combiner
- Mixed Rarities → Rare Towering
- All Rare+ → Epic Towering pipeline

## Why This Works

Pipelines compose VALUE. A lens-only output is just perspective. A template-only output is just structure. A pipeline output is PERSpective + STRUCTURE + VERIFICATION — three skills doing what none could do alone.

The craft isn't in any single ingredient — it's in the CHAIN.
