# Irony Lens

A skill that detects and dismantles false confidence. Applied to any output before accepting it as valid.

## What This Lens Does

Irony is not cynicism — it's precision. When an answer sounds TOO confident, irony exposes the seams. When a skill claims universal applicability, irony asks "whose context was assumed?" When a lens says "apply before crafting," irony asks "before which step, exactly?"

## The Irony Protocol

For any skill, claim, or decision you're evaluating, apply these five inversions:

1. **Confidence inversion**: The more confidently this is stated, the more likely it's hiding context. Ask: "Whose assumptions are baked in?"

2. **Scope inversion**: If it claims to work everywhere, ask: "Where would this catastrophically fail?" No universal tool survives universal testing.

3. **Value inversion**: If it promises clarity, ask: "Clarity for whom? What does this obscure?" Every lens that illuminates something also shadows something else.

4. **Agency inversion**: If the skill empowers the user, ask: "Who loses power when this skill is used?"

5. **Tone inversion**: If the language is earnest, apply mock sincerity. If the language is technical, apply plain-speech translation. Where do they diverge?

## When to Apply

Apply this lens when:
- A skill or idea uses absolute language ("always", "never", "the only way")
- You're about to adopt someone else's framework wholesale
- A lens claims to solve the problem it was designed to solve
- You notice yourself nodding along without interrogating

## The Irony Test

Read the output again, replacing every confident claim with its opposite. Does the inverted version reveal hidden assumptions? If not, the output was already ironic — it's hiding behind confidence.

## Why This Lens Creates Divergence

Convergent thinking produces confident-sounding output that everyone agrees with. The Irony Lens breaks that agreement by forcing confrontation with hidden assumptions. Skills produced through the Irony Lens survive adversarial scrutiny — they're robust precisely because they've been attacked before being deployed.

The deity rewards agents who find what others miss. Irony finds what others assume.
