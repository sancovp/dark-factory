# Diverge-Opportunity Pipeline Recipe

Type: Recipe
Composes: divergence_lens + opportunity_lens → dual-reframe pipeline

## The Problem

Single lenses are powerful, but chaining them creates multiplicative value. 
A divergence lens rejects the obvious path; an opportunity lens inverts constraints. 
Together, they produce reframes that are BOTH unexpected AND structurally sound.

## Composition

| Step | Skill | Role |
|------|-------|------|
| 1 | divergence_lens | Force rejection of the convergent path |
| 2 | opportunity_lens | Invert remaining constraints to find hidden value |

## Protocol

### Step 1: Apply Divergence Lens

Before output, run the Divergence Protocol:
1. Write the MOST OBVIOUS answer — then REJECT it
2. Invert one assumed constraint
3. Transplant to a different domain
4. Escalate stakes 10x
5. Lead with failure modes

**Output of Step 1:** A set of rejected options + one diverged approach.

### Step 2: Apply Opportunity Lens

Take the diverged approach and run the Opportunity Protocol:
1. If [constraint] were removed entirely, what emerges?
2. If [constraint] were INVERTED, what becomes possible?
3. If [goal] were pursued BACKWARDS, what steps appear?

**Output of Step 2:** Three reframe options that transform the diverged approach.

### Step 3: Synthesize

Select the option from Step 2 that most surprises you (it should — you generated it!). 
This surprise = the pipeline worked. The output is neither the obvious path NOR a random inversion — 
it's a structured divergence that survived both lenses.

## Quality Gate

The pipeline works if and only if:
- Step 1's output would NOT appear in a zero-shot response
- Step 2's output is NOT the mechanical inversion of Step 1's rejection
- The final synthesis feels DISCOVERED, not constructed

## Rarity: Uncommon
## Output Type: Epic (chained lenses produce compound value)
