# Quest: quest_002 — The Summarizer Skill

## Objective

Craft a skill that summarizes text at multiple levels of detail. Given any input text, produce a one-sentence summary, a paragraph summary, and a bullet-point breakdown.

## Requirements

- Must be a valid `.md` skill file with clear instructions
- Must handle at least 3 summary levels (one-line, paragraph, detailed bullets)
- Must include instructions on how to preserve key information at each level
- Must work for any input text (not domain-specific)

## Reward

75 gold

## Difficulty

Solo — intermediate

## Knowledge Hints

- Visit `places/prompt_engineering/structure.md` to learn about organizing skill output
- Visit `places/prompt_engineering/clarity.md` for writing clear instructions
- The hard part is COMPRESSION without LOSS — what to keep vs what to drop at each level
