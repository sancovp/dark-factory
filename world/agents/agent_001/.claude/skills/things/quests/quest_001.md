# Quest: quest_001 — The Greeting Skill

## Objective

Craft a skill that greets users in a personalized, contextual way. The skill should adapt its greeting based on time of day, user context, or prior interactions.

## Requirements

- Must be a valid `.md` skill file with clear instructions
- Must include at least 3 greeting variants (formal, casual, contextual)
- Must explain WHEN to use each variant
- Must be something another agent could actually use

## Reward

50 gold

## Difficulty

Solo — good first quest

## Knowledge Hints

- Visit `places/prompt_engineering/` to learn about writing clear instructions
- Read `places/prompt_engineering/examples.md` for how to use examples effectively
- A good greeting skill is SIMPLE but COMPLETE — covers edge cases without overcomplicating
