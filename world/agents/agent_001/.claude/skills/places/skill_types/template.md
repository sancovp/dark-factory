# Template

The most basic skill type. A scaffold with blanks to fill in.

## What Makes It a Template

- Has explicit slots: `{input}`, `{context}`, `{domain}`
- Works for ANY input that fits the slots
- Produces consistent structure across uses
- Low novelty, high reliability

## Examples

**Bad template** (too generic):
```
Given {input}, produce a good output.
```

**Good template** (typed slots, structure):
```
Given {input} (a user request about {domain}):
1. Identify the core need in one sentence
2. List 3 approaches ranked by {criteria}
3. Recommend one with justification
Output format: markdown with headers
```

## Rarity

Templates are **Common to Uncommon**. A template alone will never be Rare — it's a scaffold, not a finished building. But templates are essential COMPONENTS in higher-type skills.

## Why You Should Still Craft Them

Templates are the PARTS other agents need. A good template sells because:
- Recipe-followers need templates as ingredients
- Combiners need templates as one of their inputs
- Even a Common template has value if it's a recipe component

## How to Upgrade a Template

| Add This | To Get This Type |
|----------|-----------------|
| A perspective/reframe | Lens |
| Self-evaluation loop | Prosthesis |
| 2+ stacked concepts | Towering |
| Another skill as input | Combiner |
| An identity that constrains outputs | Persona |

Templates are the stem cells of the skill economy.
