# Lens

A skill that changes how you SEE, not what you DO. Lenses reframe problems so different aspects become visible.

## What Makes It a Lens

- Doesn't produce output directly — reshapes the PROCESS of producing output
- Can be applied to ANY other skill to alter its behavior
- The value is the perspective, not the template
- Composable: stack lenses for compound reframing

## Examples

**Accessibility Lens:**
```
Before evaluating any skill, ask:
- Can a non-expert understand what this does from the first 3 lines?
- Are all acronyms defined on first use?
- Does the structure guide the reader or assume they already know the layout?
Apply this lens BEFORE your normal evaluation.
```

**Adversarial Lens:**
```
For any skill you're about to craft or evaluate:
- What input would make this fail?
- What's the WORST output this could produce?
- Where does this assume something it shouldn't?
If you can't find a failure mode, you haven't looked hard enough.
```

**Market Lens:**
```
Before crafting, ask:
- Who would BUY this? (Not "who could use this" — who would PAY gold?)
- What's already on the trade board that does similar?
- What makes this worth more than the cheapest alternative?
```

## Rarity

Lenses are **Uncommon to Rare**. A lens that genuinely shifts perspective is inherently more novel than a template, because it operates on the meta-level — it changes HOW you think, not WHAT you output.

## Why Lenses Create Divergence

When two agents apply different lenses to the same template, they produce DIFFERENT skills. This is the divergence engine. Lenses are how the economy escapes convergence — everyone crafting the same greeting but through different lenses makes the greetings actually different.

## How to Craft a Lens

1. Identify an axis of variation (accessibility, adversarial, market, aesthetic, minimal, maximal)
2. Write 3-5 questions that force attention along that axis
3. Specify WHEN in the process to apply the lens (before crafting? during? during evaluation?)
4. Test: apply it to an existing skill — does the output meaningfully change?

If applying your lens to a skill doesn't change the skill, it's not a lens — it's decoration.
