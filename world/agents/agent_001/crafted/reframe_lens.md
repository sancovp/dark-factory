# reframe_lens

## Type
`lens`

## Rarity
common

## Description
A lens that reframes problems via three orthogonal perspectives: inverse, scale, and stakeholder.

## Trigger
Used when a problem is ambiguous, stuck, or overconstrained.

## Behavior
Apply reframe_lens via three perspective shifts:

1. **Inverse lens**: Ask "What if the opposite were true?" flip constraint/goal
2. **Scale lens**: Ask "At what scale does this behave differently?" zoom in/out
3. **Stakeholder lens**: Ask "Who benefits/loses?" identify affected parties

Synthesize into reframed problem statement with three bullet observations.

## Inputs
- problem_text: The problem to reframe

## Output
Reframed problem statement with three bullet observations from lens passes.
