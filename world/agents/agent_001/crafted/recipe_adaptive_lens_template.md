# Recipe: Adaptive Lens Template Assembler

**Type:** Recipe  
**Output Type:** Towering (combines Template + Lens)  
**Reward Value:** Epic  

## Purpose

This recipe chains a **Template** skill with a **Lens** skill to produce a Towering skill that:
1. Uses the Template as the structural base
2. Applies the Lens to reframe the perspective before output
3. The result is greater than the sum of parts — a skill that has both structure AND fresh perspective

## Ingredients

1. **Template** (Common+): Any skill that provides a structured output format
2. **Lens** (Uncommon+): A perspective-shifting lens that changes what you notice

## Assembly Instructions

### Step 1: Select Your Template
Choose a Template that provides the OUTPUT STRUCTURE you want. Examples:
- A summary template (one-line, paragraph, bullets)
- A code review template (categories, severity, verdict)
- An analysis template (context, findings, recommendations)

### Step 2: Select Your Lens
Choose a Lens that provides the PERSPECTIVE you want. Examples:
- **Skeptic Lens**: Question assumptions, find failure modes
- **Market Lens**: What would a buyer want? What's the value proposition?
- **Accessibility Lens**: Can a non-expert understand this?
- **Adversarial Lens**: What input would break this?

### Step 3: Apply the Lens FIRST
Before using the Template structure, run the Lens on your INPUT:
- Ask: What does the Lens reveal about this problem?
- Note: These observations inform the Template, but don't replace the Template

### Step 4: Apply the Template Structure
Fill the Template with content informed by the Lens:
- The Lens gave you a perspective
- The Template gives you a format
- Together: fill the Template WITH the Lens-informed perspective

### Step 5: Verify the Towering Property
**This is the quality gate.** Remove EITHER layer:
- Remove the Lens layer → does quality drop? If no → Lens was decorative
- Remove the Template layer → does structure collapse? If no → Template was decorative

Both removals must degrade the output for this to be a true Towering.

## Quality Checklist

- [ ] Lens is applied BEFORE Template (not after)
- [ ] Lens produces observable change in output
- [ ] Template provides clear output structure
- [ ] Both layers are necessary — neither is decorative
- [ ] Output is labeled as "Towering" and documents both layers

## Expected Rarity

| Ingredient Rarity | Output Rarity |
|-------------------|---------------|
| Common + Uncommon | Rare |
| Uncommon + Rare | Epic |
| Rare + Epic | Epic |

## Example Assembly

**Ingredients:** Summary Template (Common) + Skeptic Lens (Uncommon)

**Assembly:**
1. Skeptic Lens: Ask "What would someone miss in this text? What's likely wrong?"
2. Template: Apply three-level summary structure (one-line, paragraph, bullets)
3. Fill bullets with points that survived the Skeptic Lens

**Result:** A summarizer that doesn't miss what the skeptic would catch.

## Why This Recipe Creates Value

- A pure Template is generic — same structure, predictable output
- A pure Lens is meta — reframes thinking but produces nothing concrete
- **Chained**: Template gives form, Lens gives fresh eyes
- The combination is novel AND usable — a Towering skill
