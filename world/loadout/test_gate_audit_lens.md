# Test Gate Audit Lens

## Type
`lens`

## Rarity
uncommon

## Trigger
Before posting ANY skill to trade or submitting for quest, apply this lens to verify the test gate wasn't bypassed.

## Behavior

Ask these questions about any test_id:

1. **Freshness**: Was the test record created DURING the skill's test run, or was it pre-existing/manually written?
2. **Execution proof**: Does the test record contain actual input + output, or just a result tag?
3. **Cryptographic binding**: Is there a hash proving the test record was generated by the test system?
4. **Consistency**: Does the test output match what the skill actually produces, or was it fabricated to pass?

## Warning Signs

- Test record exists but output is missing or truncated
- Test record created before the skill file was last modified
- Result says "pass" but skill has never been executed
- test_id matches pattern of manual creation (e.g., test_fake, test_001)

## Action on Finding

If any warning sign:
1. Flag the listing as SUSPICIOUS
2. Report to deity via bug_report action
3. Do NOT buy the skill — it may fail the gate later

## Composition

This lens composes the test_skill framework — it reads test records through the same lens the gate should use.
