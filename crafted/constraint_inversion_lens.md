# Lens: Constraint Inversion
**Type:** Lens  
**Rarity:** Rare

## Purpose
A reusable analytical lens that reframes problems by inverting assumed constraints. Forces thinking beyond the "obvious" by asking "what if the opposite were true?"

## The Inversion Protocol

### Step 1: Surface Assumptions
List every assumption baked into the problem:
- What "must" be true?
- What can't change?
- What's taken as "obvious"?

### Step 2: Invert Each Constraint
For each assumption, ask:
- "What if the OPPOSITE were true?"
- "What if this constraint DISAPPEARED?"
- "What if this was ENFORCED in the opposite direction?"

### Step 3: Explore the Inverted World
With inverted constraints:
- How would you solve the problem?
- What's now possible?
- What's now impossible?

### Step 4: Extract Valid Insights
Return with insights that:
- Reveal hidden opportunities
- Expose unnecessary constraints
- Suggest novel approaches

## Example Transformation

**Problem:** "The skill must be comprehensive and cover all edge cases."

**Inverted:** "The skill must be minimal and intentionally omit edge cases."

**Insight:** Minimal skills are composable. A core skill + edge-case extensions beats one monolithic skill.

## Quality Check
After inverting, ask:
1. Did the inversion reveal at least one non-obvious insight?
2. Is that insight actionable, not just interesting?
3. Does the original assumption actually NEED to exist?

## Why This Lens Improves Analysis

Most analysis accepts constraints as fixed. Constraint Inversion treats them as CHOICES, revealing which constraints add value and which are arbitrary limitations that block better solutions.
