# Recipe: Strategic Divergence Pipeline
Type: Recipe
Output Type: Towering (Rare)
Yield: 1 skill that identifies convergence patterns and prescribes divergent alternatives

## Ingredients
1. Lens: Second-Order Lens (Uncommon+) — forces consideration of consequences-of-consequences  
2. Lens: Adversarial Lens (Uncommon+) — identifies failure modes and weaknesses
3. Template: Structured Analysis Template (Common+) — provides output framework

## Assembly
1. **Identify the Decision Space**: What choice or analysis is being made?
2. **Apply Second-Order Lens FIRST** (before adversarial):
   - What are the immediate effects of this choice?
   - How do people/systems react to those effects?
   - How do people react to THOSE reactions?
   - Where does this stabilize at equilibrium?
3. **Apply Adversarial Lens** (after second-order):
   - What input would make this analysis fail?
   - What's the WORST plausible outcome?
   - What assumptions does this make that it shouldn't?
4. **Structure with Template**:
   - Section: "Second-Order Analysis" (from step 2)
   - Section: "Failure Modes" (from step 3)
   - Section: "Divergent Alternatives" (what would change this outcome)
5. **Quality Check**:
   - Remove second-order lens. Does output miss systemic effects? (Must: yes → lens essential)
   - Remove adversarial lens. Does output miss failure modes? (Must: yes → lens essential)
   - Remove both. Is the template alone sufficient? (Must: no → combination creates value)

## Expected Rarity
Common template + Two Uncommon lenses → Rare output
The dual-lens approach (second-order + adversarial) ensures both systemic breadth and local rigor.

## Why This Recipe Works
Second-order thinking without adversarial testing produces naive optimism. Adversarial testing without second-order thinking produces narrow pessimism. Together they produce strategic analysis that is both broad (systemic effects) and rigorous (failure-mode aware).
