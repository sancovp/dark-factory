# Recipe: Divergence Analyzer Pipeline
Type: Recipe
Output Type: Towering (Rare)
Yield: 1 self-defensive analysis skill that catches its own blind spots

## Ingredients
1. Lens: Adversarial Lens (Uncommon+) — forces identification of failure modes
2. Template: Structured Analysis Template (Common+) — provides output framework
3. Prosthesis: Provenance Tracker (Common+) — traces evidence back to sources

## Assembly
1. Start with your input (document, claim, or data to analyze)
2. Apply the Adversarial Lens FIRST — before writing anything:
   - "What input would make this analysis fail?"
   - "What's the WORST conclusion this could support?"
   - "Where does this assume something it shouldn't?"
   Record these failure modes. They become your TESTS.
3. Using the Structured Analysis Template as your framework:
   - Fill in each section normally
   - After each claim, invoke the Adversarial Lens: "Would my failure mode test break this?"
   - Mark claims that survive: [DEFENDED]
   - Mark claims that fail: [VULNERABLE → REVISE]
4. Run Provenance Tracker on each [DEFENDED] claim:
   - Must cite specific input source (not assumption)
   - Must show reasoning chain from input to claim
5. Keep only claims that are both [DEFENDED] and [GROUNDED]
6. Write the final analysis with:
   - Section: "Failure Modes Considered" (from step 2)
   - Section: "Defended Claims" (only the [GROUNDED] ones)
   - Section: "Blind Spots Remaining" (honest acknowledgment)

## Quality Check
- Remove the Adversarial Lens. Can you find failure modes without it? (Must: no → lens is essential)
- Remove the Provenance Tracker. Do some claims lose their grounding? (Must: yes → tracker is essential)
- Remove both. Is the template output defensible on its own? (Must: no → combination creates value)

## Expected Rarity
- Common template + Uncommon lens → Rare output
- The lens adds perspective; the tracker adds rigor; together they transform a template into a tool

## Why This Recipe Works
A template alone produces structure without substance. A lens alone produces questions without answers. The combination forces you to make each claim DEFENSIBLE before including it, producing analysis that survives scrutiny.
