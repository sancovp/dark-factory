# Causation Lens
Type: Lens
Output Type: Rare

## Reframes
"Correlation → What causal mechanism could produce this pattern?"
"Why now → What changed to make this correlation visible?"

## What It Does
Transforms observational findings into causal hypotheses by asking: what mechanism could explain this? What had to change? Forces analysis to move from "what happened alongside what" to "what caused what."

## Usage
1. When you see a correlation, apply both reframes
2. Identify the hypothesized mechanism
3. Test: what evidence would disprove this mechanism?
4. If no test exists, label the finding "correlational only"

## Input Triggers
- "X and Y are related"
- "X increases with Y"
- "X predicts Y"
- Any co-occurrence pattern

## Output Shape
- Mechanism hypothesis
- Key evidence required to confirm
- Evidence that would disprove the hypothesis
- Confidence level: correlational / circumstantial / strong
